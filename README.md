# Página personal para búsqueda de empleo

Este repositorio contiene una página personal estática pensada para desplegar en GitHub Pages.

## Archivos

- `index.html`: Página principal.
- `styles.css`: Estilos CSS de la página.

## Cómo usar

1. Personaliza el contenido de `index.html` con tu nombre, experiencia, proyectos y datos de contacto.
2. Ajusta los estilos en `styles.css` si quieres cambiar colores o tipografía.
3. Crea un commit y publícalo en GitHub.

## Despliegue en GitHub Pages

- Si el repositorio se llama `usuario.github.io`, GitHub Pages publica automáticamente el contenido de la rama `main` desde la raíz.
- Si el repositorio tiene otro nombre, ve a **Settings > Pages** y configura la rama `main` y la carpeta `/ (root)`.

## Recomendaciones

- Añade tu foto profesional y enlaces a LinkedIn, GitHub y correo.
- Incluye proyectos concretos con resultados claros.
- Mantén el diseño limpio y fácil de leer.
